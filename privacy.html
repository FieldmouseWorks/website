Privacy

Last updated 23 October 2026.

This website sets no cookies, runs no analytics or trackers, and collects no personal information. Like any web server, it keeps standard access logs (IP address, time, page requested) to keep the site running and secure, and they aren't shared with anyone.

remi-rclone

remi-rclone is a private Google OAuth client used only by Fieldmouse Works' own server to back up its owner's files to their own Google Drive with rclone. It signs in to that one Google account and nothing else. Data from Google APIs is used only to read and write those backups, and is never sold, shared or transferred to anyone. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
